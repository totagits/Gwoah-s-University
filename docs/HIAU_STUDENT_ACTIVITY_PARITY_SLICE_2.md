# HIAU student activity — controlled migration slice 2

The original Google AI Studio Student Activity Timeline used `INITIAL_STUDENT_ACTIVITIES` from seed data. It is preserved in `main` as a visual reference, but demonstration events are **not** imported.

This slice uses the existing immutable SQLite `audit` entries generated by `Operations.execute`. The dedicated `GET /api/workspaces/student-activity` route only accepts an authenticated student actor and returns their most recent 40 supported academic actions (`register`, `drop`, `graduationRequest`, `transcriptRequest`). Response fields are restricted to `id`, `action`, and `created_at`, with no before/after audit JSON, entity identifiers or unrelated user records.

The existing `/api/workspaces/state` endpoint is also redacted for non-auditor users to remove raw audit before/after JSON. Super Administrator and Registrar audit views retain their existing privileged scope.

The secure student overview now displays a real student timeline, truthful empty state, and explicit API error state. It does **not** claim to show actions performed by staff, automated notifications, or the complete academic history. Remaining messaging, peer discussion, facilities and notifications require distinct back-end authorization and data-reconciliation work.

Before production: verify through an actual student account with real registration and transcript events, and inspect that unrelated student records remain inaccessible.
