# HIAU Academics — institutional layout refresh and Civil Engineering credit decision

## Design reference and boundary

The HIAU Academics public page uses [Purdue University in Indianapolis](https://www.purdue.edu/indianapolis/) as a **structural inspiration only**:
- Clear academic introduction with university-specific typography and CTAs
- College navigation separated from degree-program discovery
- A readable two-column navigation/content layout and program search
- Distinct experiential learning block, not competing with the college directory
- Vocational and enrichment information in restrained editorial lists
- Responsive containers, reduced visual clutter, accessible selected navigation

No Purdue logo, copy, photography, source code, or brand styling is copied. HIAU retains its original purple-and-gold identity and university photograph.

## Corrections to previous Academics page

- Removed large photo feature from above the college directory, where it displaced the main task of finding programs.
- Removed oversize five-button segmented control and competing all-uppercase banners.
- Removed blanket `NCHE Accredited` labels from every degree card; HIAU must confirm accreditation program by program.
- Removed `Statutory 120–132 Semester Credits` badge, which was inappropriate for Civil Engineering and other curricula.
- Removed blanket `Semester I & II Intake` claim and replaced it with university-verification guidance.
- Kept the BLEST college organization, all original college/program descriptions, original image asset, TVET and enrichment listings.
- Replaced unsupported current-availability assertions with verification language where necessary.

## Civil Engineering credit determination

**Decision from HIAU stakeholder on November 8, 2026: use 179 total credits for Civil Engineering.** The stored reference candidate has:
- General education: 44 credits
- College core: 36 credits
- Major/content: 90 credits
- Electives: 9 credits
- **Total: 179 credits**

Source PDF (College of Science, pp. 9–10) mentions 177 as a competing total and 90/91 content-credit discrepancy. These are preserved in source notes as historical conflicts, while the **HIAU-confirmed total is 179**.

This updates the reference intake package only. The program remains `REF-*` and `SOURCE_REVIEW_REQUIRED` until official course sequence, program ID, admissions availability and approval are verified. It does not silently modify published or existing live student records.
